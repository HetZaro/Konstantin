САЙТ-РЕЗЮМЕ — ПУКАС КОНСТАНТИН ЮРЬЕВИЧ

Как открыть:
1. Распакуйте архив в любую папку.
2. Откройте index.html в браузере.

Как добавить личное фото:
1. Сохраните фотографию в папку assets под именем photo.jpg.
2. Откройте index.html и найдите строку:
   <img src="assets/photo-placeholder.svg" ...
3. Замените путь на:
   <img src="assets/photo.jpg" ...

Перед публикацией обязательно замените your-email@example.com на свою электронную почту
(в index.html есть несколько вхождений). При необходимости поправьте уровни навыков,
добавьте даты практик и конкретные задачи, которые выполняли.

Сайт адаптирован для телефонов и компьютеров. Есть переключатель тёмной темы.
